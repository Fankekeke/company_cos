# 基于 SpringBoot + Vue 的企业专家交流平台 (Enterprise Expert Exchange Platform)

专家入驻 · 技术咨询 · 项目协作 · 人才推荐 · 技术难点对接 · 即时沟通 · 企业收藏 · 公告管理

本项目是一套面向企业、行业专家及技术人才的产学研对接与知识共享平台，采用前后端分离架构，覆盖管理员、企业、专家与游客四类角色。系统围绕"企业管理、专家管理、技术咨询、技术难点发布、项目成果管理、人才推荐、即时沟通、企业收藏、公告管理"等核心业务设计，支持企业发布技术需求与咨询问题、专家提供专业解答与项目合作、人才推荐与匹配、即时消息沟通，管理员负责平台运营、内容审核与数据管理，实现从技术需求发布、专家对接、项目协作到人才推荐的全流程数字化服务，适用于产学研合作平台、行业专家咨询系统、企业技术难题攻关平台及技术人才对接平台。

## 核心特性

- **多角色权限管理**：区分管理员、企业、专家与游客四类角色，实现不同权限隔离与功能访问控制。
- **企业入驻与管理**：企业可注册并完善企业信息（名称、行业、规模、简介、联系方式），管理员审核与管理企业信息。
- **专家入驻与管理**：专家可注册并完善个人信息（姓名、领域、职称、研究方向、工作经历、擅长技术），管理员审核与管理专家信息。
- **技术咨询与沟通**：企业可向专家发起技术咨询，专家在线回复解答，支持文字、图片沟通，聊天记录可追溯。
- **技术难点发布**：企业发布技术难点与攻关需求，专家浏览并认领，形成技术需求与专家能力的精准匹配。
- **项目成果管理**：记录企业与专家合作的项目信息，包括项目名称、合作双方、项目周期、成果描述、成果文件，支持项目成果展示。
- **人才推荐**：系统根据企业需求与专家/人才的专业领域、技能标签进行智能匹配推荐，游客也可浏览推荐人才信息。
- **企业收藏**：企业可收藏感兴趣的专家，专家可收藏关注的企业，方便后续沟通与合作。
- **消息通知**：系统实时推送消息通知，包括咨询回复、项目邀请、人才推荐、系统公告等，确保信息及时触达。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、用户管理、内容审核与系统维护：

### 用户与主体管理

- **用户管理**：管理注册用户信息，包括姓名、手机号、角色类型（企业/专家）、注册时间、账户状态，支持账号启用/禁用。
- **企业管理**：管理入驻企业信息，包括企业名称、行业、规模、简介、联系方式、认证状态，支持企业信息编辑与审核。
- **专家管理**：管理入驻专家信息，包括专家姓名、所属领域、职称、研究方向、工作经历、认证状态，支持专家信息编辑与审核。

### 内容与沟通管理

- **公告信息管理**：发布平台公告，包括活动通知、规则变更、系统维护通知、合作动态等，支持置顶与定时发布。
- **聊天记录**：查看企业与专家之间的咨询沟通记录，支持消息审核与异常消息处理，保障沟通合规。
- **消息通知管理**：查看系统消息发送记录，包括咨询回复通知、项目邀请通知、人才推荐通知等，支持消息推送配置。

### 业务管理

- **项目成果管理**：查看平台所有合作项目信息，包括项目名称、合作企业与专家、项目周期、成果描述、成果文件，支持项目审核与成果展示管理。
- **人才推荐管理**：配置人才推荐规则与标签体系，查看推荐匹配记录，优化推荐算法参数。
- **企业收藏管理**：查看企业收藏专家、专家收藏企业的记录，支持异常收藏行为处理。

## 企业端

企业面向平台入驻企业用户，提供技术需求发布、专家咨询、项目合作与人才推荐功能：

### 企业信息管理

- **企业信息管理**：完善与维护企业信息，包括企业名称、所属行业、企业规模、企业简介、联系方式、企业 logo，支持信息编辑与更新。

### 技术咨询与沟通

- **技术咨询**：浏览专家列表，按领域、研究方向等条件筛选，向目标专家发起技术咨询，描述技术问题与需求，等待专家回复。
- **沟通咨询**：与专家进行实时在线沟通，查看历史聊天记录，发送文字与图片消息，跟进咨询进展。

### 技术难点与项目

- **技术难点**：发布企业当前面临的技术难点与攻关需求，包括难点描述、技术领域、期望解决时间、预算范围，供专家浏览与认领。
- **我的项目**：查看与专家合作的项目列表，包括项目状态（进行中/已完成）、项目周期、成果描述，支持上传项目成果文件。

### 收藏与推荐

- **我的收藏**：查看收藏的专家列表，方便后续咨询与合作；支持取消收藏。
- **人才推荐**：浏览系统推荐的技术人才与专家，查看人才专业领域、技能标签、过往项目经历，发起合作邀请。

---

## 专家端

专家面向平台入驻专家，提供技术咨询回复、项目协作与企业管理功能：

### 专家信息管理

- **专家信息管理**：完善与维护个人信息，包括姓名、所属领域、职称、研究方向、工作经历、擅长技术、个人简介、头像，支持信息编辑与更新。

### 技术咨询与沟通

- **沟通咨询**：查看企业发起的咨询请求，在线回复解答技术问题，与企业管理实时沟通，查看历史聊天记录。

### 项目与难点

- **我的项目**：查看参与的合作项目列表，包括项目名称、合作企业、项目周期、项目状态，支持上传项目成果文件与更新项目进展。
- **企业技术难点**：浏览企业发布的技术难点列表，按领域筛选，认领感兴趣的技术难点，与企业进一步沟通合作细节。

### 收藏

- **我的收藏**：查看收藏的企业列表，关注潜在合作机会；支持取消收藏。

---

## 游客端

游客面向未登录用户，提供有限的内容浏览功能：

- **人才推荐浏览**：浏览平台推荐的技术人才与专家基本信息（姓名、领域、职称、研究方向），了解平台专家资源，注册后可发起合作。
- **公告浏览**：浏览平台公开公告信息。
